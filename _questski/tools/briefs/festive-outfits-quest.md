== Outfit ==
[[First Dragon Quest]]

== Addon 1 ==
Required items:
* 3 [[Porcelain Mask]]
Go to [[Muriel]] in Thais.

Greet him and ask for an 'outfit', then say 'yes', 'yes', 'mask'

== Addon 2 ==
Required items:
* 50 [[Colourful Feathers]]
Go to [[Muriel]] in Thais.

Greet him and ask for an 'outfit', then say 'yes', 'yes', 'feather'
