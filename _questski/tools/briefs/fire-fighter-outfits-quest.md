== Base Outfits ==

Finish [[Primal Ordeal Quest]] by defeating [[Magma Bubble]].

== First Addon ==

Use a {{Ilink|Firefighting Axe}} [[Firefighting Axe]].<br />
You will see the following message: {{Sound|You feel like fighting a fire!}}

== Second Addon == 

Use a {{Ilink|Portable Flame}} [[Portable Flame]].<br />
You will see the following message: {{Sound|The flame engulfs you!}}

Upon using both items you will get the achievement [[Friendly Fire]].
