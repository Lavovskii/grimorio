## SPOILER PAGE (walkthrough source)

{{spoiler|name=Crystal Warlord Outfits Quest}}
'''Note:''' [[Minor Crystalline Token|Minor]] and [[Major Crystalline Token]]s, as well as [[Gnomish Supply Package]]s that are required for this quest can be obtained via [[Bigfoot's Burden Quest]]. Also, you do not have to get the items by yourself — buying them from other players will have the same effect.

==Base Outfit==
[[File:Outfit_Crystal_Warlord_Male.gif]][[File:Outfit Crystal Warlord Female.gif]]

===Required Equipment===
[[File:Gnomish Voucher Type CB.gif]] [[Gnomish Voucher Type CB]] 

===Method===
Simply use a [[Gnomish Voucher Type CB]] to obtain the outfit. It can be obtained by exchanging 20 [[Major Crystalline Token]]s with NPC [[Gnomally]].

==Addon 1 (Cape and Mask)==
[[File:Outfit_Crystal_Warlord_Male_Addon_1.gif]][[File:Outfit Crystal Warlord Female_Addon_1.gif]]

===Required Equipment===
[[File:Gnomish Voucher Type CA1.gif]] [[Gnomish Voucher Type CA1]]

===Method===
Simply use a [[Gnomish Voucher Type CA1]] to obtain the first addon. It can be obtained by exchanging 70 [[Minor Crystalline Token]]s with NPC [[Gnomally]].

==Addon 2 (Shield and Club)==
[[File:Outfit_Crystal_Warlord_Male_Addon_2.gif]][[File:Outfit Crystal Warlord Female_Addon_2.gif]]

===Required Equipment===
[[File:Gnomish Voucher Type CA2.gif]] [[Gnomish Voucher Type CA2]]

===Method===
Simply use a [[Gnomish Voucher Type CA2]] to obtain the second addon. You have a small chance of getting the voucher when using [[Gnomish Supply Package]]s.
