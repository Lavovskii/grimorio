## SPOILER PAGE (walkthrough source)

{{spoiler|name=Soil Guardian Outfits Quest}}
'''Note:''' [[Minor Crystalline Token|Minor]] and [[Major Crystalline Token]]s, as well as [[Gnomish Supply Package]]s that are required for this quest can be obtained via [[Bigfoot's Burden Quest]]. Also, you do not have to get the items by yourself — buying them from other players will have the same effect.

==Base Outfit==
[[File:Outfit_Soil Guardian_Male.gif]][[File:Outfit Soil Guardian Female.gif]]

===Required Equipment===
[[File:Gnomish Voucher Type MB.gif]] [[Gnomish Voucher Type MB]]

===Method===
Simply use a [[Gnomish Voucher Type MB]] to obtain the outfit. It can be obtained by exchanging 20 [[Major Crystalline Token]]s with NPC [[Gnomally]].

==Addon 1 (Cape)==
[[File:Outfit_Soil Guardian_Male_Addon_1.gif]][[File:Outfit Soil Guardian Female_Addon_1.gif]]

===Required Equipment===
[[File:Gnomish Voucher Type MA1.gif]] [[Gnomish Voucher Type MA1]]

===Method===
Simply use a [[Gnomish Voucher Type MA1]] to obtain the first addon. It can be obtained by exchanging 70 [[Minor Crystalline Token]]s with NPC [[Gnomally]].

==Addon 2 (Shield)==
[[File:Outfit_Soil Guardian_Male_Addon_2.gif]][[File:Outfit Soil Guardian Female_Addon_2.gif]]

===Required Equipment===
[[File:Gnomish Voucher Type MA2.gif]] [[Gnomish Voucher Type MA2]]

===Method===
Simply use a [[Gnomish Voucher Type MA2]] to obtain the second addon. You have a small chance of getting the voucher when using [[Gnomish Supply Package]]s.
