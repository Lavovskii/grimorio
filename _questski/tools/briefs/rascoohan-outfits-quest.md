## SPOILER PAGE (walkthrough source)

{{Spoiler|name=Rascoohan Outfits Quest}}

== Base Outfits ==

Finish [[A Pirate's Tail Quest]] by defeating [[Ratmiral Blackwhiskers]]. 

== First Addon ==

Use a {{Ilink|Soap}} [[Soap]].<br />
You will see the following message: {{Sound|You feel a bit more raccoonish.}}

== Second Addon == 

Use a {{Ilink|Scrubbing Brush}} [[Scrubbing Brush]].<br />
You will see the following message: {{Sound|Hmmm, trash cans!!}}

Upon using both items you will get the achievement [[Honorary Rascoohan]].
