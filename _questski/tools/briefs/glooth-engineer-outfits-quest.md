## SPOILER PAGE (walkthrough source)

{{spoiler|name=Glooth Engineer Outfits Quest}}

== Requirements ==

* For the base outfit: complete of the [[Dark Trails Quest]].
* For the first addon: base outfit, Inhabitant rank in the [[Rathleton Quest]] and votes cast towards each of the available "shortcuts" and "dungeon" topics at least once.
* For the second addon: base outfit, first addon, Inhabitant rank in the [[Rathleton Quest]] and votes cast towards each of the available "bosses" topic at least once.

== Base Outfit ==
[[File:Outfit_Glooth_Engineer_Male.gif]][[File:Outfit Glooth Engineer Female.gif]]

Complete the [[Dark Trails Quest]] ask [[Ezebeth]] about an '''outfit'''.

== Addon 1 ==
[[File:Outfit_Glooth_Engineer_Male_Addon_1.gif]][[File:Outfit Glooth_Engineer Female_Addon_1.gif]]

Obtain the base outfit, have inhabitant rank of status, and then cast at least one vote (earned in the [[Oramond Quest]]) on each '''shortcut''' and one vote on each '''dungeon''' in the [[Rathleton Quest]]. Afterwards, [[Ezebeth]] about an '''addon'''.

== Addon 2 ==
[[File:Outfit_Glooth_Engineer_Male_Addon_2.gif]][[File:Outfit Glooth_Engineer Female_Addon_2.gif]]

Obtain the base outfit and the first addon, have inhabitant rank of status, and then cast at least one vote (earned in the [[Oramond Quest]]) on each '''boss''' in the [[Rathleton Quest]]. Afterwards, [[Ezebeth]] about an '''addon'''.

'''Note: A total of 150 votes will already have to have been cast by you in order to be able to vote on bosses.'''

== Reward ==
Besides the [[Glooth Engineer Outfits]] you will also receive the [[Glooth Engineer]] [[achievement]] upon completion of this quest.
