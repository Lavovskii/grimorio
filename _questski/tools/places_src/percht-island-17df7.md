 The Percht Island is a secret island that can only be reached when the Winterlight Solstice begins. To visit it, use the small boat that is anchored nearby Svargrond 's harbor.
 This island shares a location with the Orcsoberfest Island , which is why it may odd on the Automap if you have visited both of them. Which area is active depends on the event that is running. You can see the map that corresponds only to the Percht Island on the images to the right. The region that hosts the island is called Secluded Island , and that's the name that appears in e.g. the Bestiary of the creatures.
